### 🎛️ Core Features

- 🎶 **Custom Audio Engine:** Play/pause, track switching, and interactive seek bar.
- 📌 **Dynamic Playlist:** Real-time track bookmarking and playlist management.
- 🔊 **Smart Volume Controls:** Smooth volume slider with instant mute toggling.
- 🎨 **Dark Aesthetic:** Responsive Spotify-style UI powered by Flexbox & CSS Grid.

---

### 🛠️ Tech Stack

- **HTML5** — Native `<audio>` API & semantic markup
- **CSS3** — Custom layouts, Flexbox & CSS Grid
- **JavaScript** — Pure ES6+ DOM manipulation & state logic
